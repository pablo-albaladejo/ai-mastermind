# ai-mastermind

Self-hosted AI observability and optimisation, running on a home Mac mini.

**Phase 1 (current): observability.** A self-hosted Langfuse instance collecting
traces from Claude Code and Cursor across multiple machines and accounts, via an
OpenTelemetry Collector.

Later phases build on that trace store: cost/efficiency dashboards, knowledge
graphs, and evals.

See [`docs/PLAN.md`](docs/PLAN.md) for the architecture, the verified constraints
it is built around, and the phased plan.

## Status

Planning. Nothing is deployed yet.
